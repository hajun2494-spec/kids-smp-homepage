# EVERGREEN SMP 홈페이지

Java와 Bedrock에서 함께하는 에버그린 SMP의 [공식 홈페이지](https://mcevergreensmp-hub.github.io/kids-smp-homepage/)입니다. [마을 지도](https://mcevergreensmp-hub.github.io/kids-smp-homepage/map.html)와 [방송 페이지](https://mcevergreensmp-hub.github.io/kids-smp-homepage/broadcast.html)도 이 저장소에서 운영합니다.

- 접속 주소: `eversmp.kro.kr`
- Java 포트: `25565` · Bedrock 포트: `19132`
- 운영 시간: 한국 시간 기준 매일 07:00–23:00
